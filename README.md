# Daily Fashion Deals Hub

A single-page static website for the Daily Fashion Deals Hub AJIO affiliate campaign.

## Files
- `index.html` — page content
- `style.css` — responsive design
- `script.js` — category filtering and dynamic year

## Run locally
Open `index.html` directly in a browser, or use VS Code Live Server.

## GitHub Pages
1. Create a GitHub repository, for example `daily-fashion-deals-hub`.
2. Upload `index.html`, `style.css`, and `script.js`.
3. Go to **Settings → Pages**.
4. Select **Deploy from a branch**.
5. Select `main` and `/ (root)`.
6. Save.
7. GitHub will give you a public URL.

## Important
The links are affiliate/deep links supplied for the campaign. Do not replace them with ordinary AJIO URLs if tracking is required.

The Levi's campaign creative says ₹899 while the supplied URL slug contains `atrs999`; verify the live offer before publishing.

Prices, stock, sizes and offers can change. Keep the disclosure on the page.
